# Backend Modules

## 1. Authentication
* Request OTP
* Verify OTP
* Login/Logout
* Authentication and authorization

## 2. Users
* Manage global user information

## 3. Groups
* Create/View groups
* Manage group members
* Leave group
* Validate whether a user can leave
* Handle group becoming inactive

## 4. Invitations
* Create invitation
* Validate invitation
* Accept invitation
* Handle invitation expiration

## 5. Expenses
* Add/Edit/Delete expense
* View expenses
* Validate expenses
* Calculate equal split
* Calculate unequal split
* Enforce expense edit/delete permissions

## 6. Settlements
* Record settlement
* Validate settlement

## 7. Balances
* Calculate balances from expenses and settlements
* Net opposite balances
* Return user balances

## 8. Notifications
* Notify group members about relevant changes

## 9. Export
* Collect group expenses and settlements
* Generate CSV
