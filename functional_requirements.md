# User Management

1. User can create account using email
2. user can log in using email and otp sent to that email
3. user email must be verified through otp before account can be used
4. user can log out

# Groups

5. user can create group and view groups they belong to
6. user can invite other users to a group
7. users can view the members of a group

# Expenses

8. any member of group can add an expense
9. each expense contains
   * total amount
   * who paid the money
   * which members are involved in the expense
   * how the expense is split
10. expense can be split equally or unequally
11. user can edit/delete only the expense they have created
12. users can view all expenses belonging to a group

# Settlements

13. A user can record a settlement where one person pays another person a specified amount.

# Balances

14. Each user can see the total amount they are owed
15. Each user can see the total amount they owe.
16. Each user can see who owes them and how much.
17. Each user can see whom they owe and how much.

# Notification

18. Group members are notified when an expense is added, edited, or deleted.

# Export

19. Users can export the expense data of a group
