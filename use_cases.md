## 1. Register/Login a User

* User -> enters email
* gets otp to verify email
* after verifying -> gets logged in

## 2. Create Group

* user -> click create group
* add group details
* group created

## 3. Invite People

* user opens group
* click the invite option
* enter the email
* invite sent

## 4. Add Expense

* user opens group
* click to add expense
* enter the details
  * short description
  * total amount
  * who paid the money
  * money is split between
  * select split method
    * equally
    * unequally → specify amount for each person
* expense added

## 5. Delete Expense

* user opens group
* click the delete button on the expense they have added
* pop-up to confirm
* expense deleted

## 6. Edit Expense

* user opens group
* click the edit button on the expense they have added
* change the details
* expense edited

## 7. Record Settlement

* user opens group
* click the settle option
* select who paid
* select who received the payment
* enter the amount
* settlement added

## 8. View Group

* user opens group
* group members are shown
* all expenses of the group are shown

## 9. View Balances

* user opens group
* click view balances
* total amount owed to the user is shown
* total amount the user owes is shown
* users who owe money to the user with the amount are shown
* users whom the user owes money with the amount are shown

## 10.  Export Group Data

* user opens group
* click to eport data
* a csv file is ready containing all the expenses and settlements of the group

## 11. Accept Group Invitation

* user receives group invitation via email
* user opens the invitation
* user logs in/verifies email if not already logged in
* user view the group invitation
* user accepts the invitation
* user becomes a member of the group
